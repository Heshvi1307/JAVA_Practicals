
# 📚 WEEK-1 Practicals

## 1️⃣ Vending Machine

**File:** `VendingMachine.java`

### Objective
Simulate a vending machine that accepts different coin denominations until the required amount is collected...

### Concepts Covered
- Enums
- Switch Expressions
- Loops
- User Input using Scanner

### Features
- Accepts four coin types:
  - ONE
  - TWO
  - FIVE
  - TEN
- Calculates the running total.
- Stops when the total reaches or exceeds ₹15.
- Displays the change to return.

## 2️⃣ Toll Booth Management

**File:** `Tollbooth.java`

### Objective
Implement a toll booth management system that calculates total toll collection and identifies the most frequent vehicle type.

### Concepts Covered
- Records
- Switch Expressions
- Loops
- String Handling
- Scanner Class

### Toll Rates

| Vehicle | Toll |
|---------|-----:|
| Bike | ₹20 |
| Car | ₹50 |
| Truck | ₹150 |

### Features
- Stores vehicle number and type using a Java Record.
- Calculates total toll collected.
- Counts each vehicle type.
- Displays the most frequent vehicle category.

---

## 3️⃣ Rock Paper Scissors Lizard Spock

**File:** `RPSLS.java`

### Objective
Implement the extended Rock-Paper-Scissors game using Java Enums and Switch Expressions.

### Concepts Covered
- Enums
- Switch Expressions
- Methods
- Random Class
- Game Logic

### Features
- Supports five moves:
  - ROCK
  - PAPER
  - SCISSORS
  - LIZARD
  - SPOCK
- Plays five rounds against the computer.
- Determines the winner of each round.
- Maintains and displays the final score.

Run the program:

