# 📚 WEEK-3 Practicals

## 1️⃣ Distinct Points

**Files:** `Point.java` + `PointDriver.java`

### Objective

Create a Point class and count the number of **distinct points** from a set of points containing repeated coordinates...

### Concepts Covered

* Classes and Objects
* Constructors
* Encapsulation
* `equals()` Method
* `toString()` Method
* Arrays
* Nested Loops

### Features

* Creates Point objects using **x and y coordinates**.
* Compares points using `equals()`.
* Identifies repeated coordinates.
* Counts and displays the total number of distinct points.

### Concepts Covered

## 3️⃣ Fractions

**Files:** `Fraction.java` + `FractionDriver.java`

### Objective

Create a Fraction class that reduces fractions to their **lowest terms** and checks equality between equivalent fractions.

### Concepts Covered

* Classes and Objects
* Constructors
* Encapsulation
* GCD
* `equals()` Method
* `hashCode()` Method
* `toString()` Method

### Features

* Creates fractions using numerator and denominator.
* Reduces fractions using **GCD**.
* Compares fractions using `equals()`.
* Displays fractions in `num/den` format.
* Demonstrates that equivalent fractions such as `1/2`, `2/4`, and `3/6` are equal.
