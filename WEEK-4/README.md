# 📚 WEEK-4 Practicals

## 1️⃣ Password Strength Checker

**Files:** `PasswordChecker.java` + `DriverP.java`

### Objective
Implement a password strength checker that evaluates passwords based on four predefined rules...

### Concepts Covered
- Classes and Objects
- Methods
- String Methods
- Regular Expressions
- Conditional Statements
- Loops

### Features
- Checks whether the password has at least **8 characters**.
- Checks for an **uppercase letter**.
- Checks for a **digit**.
- Checks for a **special character**.
- Counts the number of rules satisfied.
- Classifies passwords as **Weak, Medium, or Strong**.

## 2️⃣ Chat-Log Filter

**Files:** `ChatFilter.java` + `DriverC.java`

### Objective
Implement a chat-log filtering system that searches messages for a user-provided keyword.

### Concepts Covered
- Classes and Objects
- Arrays
- `split()` Method
- `StringBuilder`
- String Methods
- Loops
- Conditional Statements

### Features
- Stores chat-log lines in a `String[]`.
- Reads a keyword from the user.
- Splits each log into **time, user, and message**.
- Skips malformed log entries.
- Searches messages for the keyword.
- Performs a **case-insensitive** search.
- Counts matching messages.
- Builds and displays a formatted report.

## 3️⃣ Template Filler

**Files:** `TemplateFiller.java` + `Driver.java`

### Objective
Implement a template filler that replaces placeholders with their corresponding values.

### Concepts Covered
- Classes and Objects
- Arrays
- Regular Expressions
- `Pattern`
- `Matcher`
- `StringBuilder`
- String Manipulation

### Features
- Uses placeholders such as `{name}`, `{id}`, and `{date}`.
- Finds placeholders using a regular expression.
- Searches for corresponding values in parallel arrays.
- Replaces supplied placeholders with their values.
- Replaces missing placeholders with `[?]`.
