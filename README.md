# ☕ JAVA Practicals

Welcome to my **Java Practicals** repository!

This repository contains the Java programs and practical assignments that I complete during my Java Programming Laboratory. It serves as a record of my learning journey, with all practicals organized week-wise for easy navigation and future reference.

The repository includes Java programs covering various programming concepts such as:

- Java Fundamentals
- Object-Oriented Programming (OOP)
- Enums
- Records
- Switch Expressions
- Control Statements
- Methods
- Exception Handling
- Collections
- File Handling
- And many more...

## Repository Organization

All practicals are organized into separate folders based on the corresponding laboratory week. Each week's folder contains:

- Java source files (`.java`)
- A dedicated `README.md` describing that week's practicals

## Purpose

- Track my progress throughout the semester
