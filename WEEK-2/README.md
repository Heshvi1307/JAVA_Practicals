# 📚 WEEK-2 Practicals

## 1️⃣ Smart Thermostat

**File:** `Thermostat.java`

### Objective
Implement a smart thermostat that maintains room temperature within a predefined range...

### Concepts Covered
- Classes and Objects
- Constructors & Constructor Chaining
- Static Variables
- Static Final Constants
- Encapsulation
- Loops

### Features
- Creates thermostat objects with a location and starting temperature.
- Maintains temperature between **16°C** and **30°C**.
- Prevents temperatures from exceeding the allowed range.
- Tracks the total number of active thermostat objects.
- Demonstrates temperature changes using loops.

## 2️⃣ Cinema Show Management

**File:** `CinemaShow.java`

### Objective
Simulate a cinema ticket booking system that manages seat reservations and cancellations.

### Concepts Covered
- Classes and Objects
- Constructors & Constructor Chaining
- Encapsulation
- Static Variables
- Final Variables
- Methods

### Features
- Creates cinema shows with customizable or default seating capacity.
- Books seats only when sufficient seats are available.
- Cancels bookings without exceeding the maximum capacity.
- Tracks the total number of seats booked across all shows.
- Displays booking status and available seats after each operation.

---

## 3️⃣ Parking Lot Management

**File:** `ParkingLot.java`

### Objective
Implement a parking lot management system that tracks vehicle parking, occupancy, and revenue.

### Concepts Covered
- Classes and Objects
- Encapsulation
- Static Variables
- Final Variables
- Conditional Statements
- Methods

### Features
- Manages separate parking spaces for two-wheelers and four-wheelers.
- Prevents parking when a section reaches full capacity.
- Allows vehicles to leave without reducing counts below zero.
- Calculates total parking revenue.
- Displays final occupancy and revenue after simulation.
